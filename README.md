# Pero

Дневник тренировок для Android (и iOS): программа, запись подходов, таймер отдыха, прогресс, экспорт в Excel.
Тяжело в зале, легко в записи.

## Что умеет

- **Тренировка.** Подходы с результатом прошлого раза, вес подставляется сам, кнопки ±0,5 кг и ±шаг упражнения, RIR одной кнопкой (с пояснением), отметка подхода, разминочные подходы по кнопке, варианты упражнения (штанга/гантели/угол скамьи) со своей историей весов, режим «по одной стороне» с записью левой и правой отдельно, суперсеты.
- **Таймер отдыха.** Запускается кнопкой, время из программы, ±15 с, в конце звук и вибрация (и при заблокированном экране). Фактическое время отдыха сохраняется.
- **Подсказки прогрессии.** Двойная прогрессия: все подходы на верхней границе диапазона с нужным RIR → «пора +2,5 кг».
- **Программа.** Конструктор в приложении (дни, расписание по дням недели или по кругу, подходы, повторения, RIR, отдых, суперсеты, разгрузка) или файл YAML, который можно написать самому или попросить нейросеть. Импорт показывает ошибки по строкам.
- **Прогресс.** Расчётный 1ПМ по каждому упражнению, рабочие подходы на мышцу за неделю против плана (зона 10–20), тоннаж, отдых, самочувствие и усталость, вес тела со средним за неделю, календарь тренировок.
- **Серия по неделям** с заморозкой и **ачивки** со смешными названиями.
- **Экспорт в Excel** (5 листов: тренировки, подходы, лучшие результаты, объём по мышцам, вес тела) и бэкап одним файлом.
- **Виджет** на рабочий стол Android: серия, неделя, следующая тренировка.
- Три темы: Графит (тёмная), Мел (светлая), Энергия (яркая).

## Как поставить на телефон (Android)

Сборка APK идёт в облаке Expo, компьютер нужен только чтобы запустить команду.

1. Поставь [Node.js 22](https://nodejs.org) и зарегистрируйся на [expo.dev](https://expo.dev) (бесплатно).
2. В папке проекта:
   ```bash
   npm install
   npx eas-cli@latest login
   npx eas-cli@latest build --platform android --profile preview
   ```
   При первом запуске EAS спросит, создать ли проект и ключ подписи. Отвечай «да».
3. Через 10–20 минут в терминале и на expo.dev появится ссылка на APK. Открой её на телефоне, скачай и установи (разреши установку из этого источника).

Обновлённую версию ставишь так же, поверх старой: данные сохранятся.

### Разработка

```bash
npm install
npx eas-cli@latest build --platform android --profile development   # один раз: dev-сборка
npm start                                                          # сервер, изменения видны на телефоне сразу
npm test                                                           # тесты логики
npm run typecheck                                                  # проверка типов
```

Expo Go не подойдёт: в приложении есть виджет и нативные модули, нужна своя dev-сборка.

## Как устроен код

```
library/exercises.yaml   библиотека упражнений (49 шт.): мышцы, варианты, шаг веса, техника
programs/*.yaml          встроенные программы (верх/низ, фулбади, тяни-толкай-ноги, сплит)
docs/program-format.md   формат программы и промпт для нейросети
schema/                  JSON Schema формата (подсказки в VS Code)

src/core/       чистая логика без интерфейса, покрыта тестами
  program.ts      разбор, проверка и запись программы
  training.ts     прогрессия, разминка, 1ПМ, объём по мышцам, расписание
  streak.ts       серия по неделям
  achievements.ts ачивки (добавить новую = один объект в списке)
src/db/         SQLite: схема с миграциями и все запросы
src/features/   сценарии: начало тренировки, таймер, файлы и Excel, ачивки
src/ui/         элементы интерфейса, графики, иконки
src/theme/      темы: все цвета и шрифты в одном файле
src/app/        экраны (expo-router: каждый файл = экран)
src/widget/     виджет рабочего стола
```

**Хранение.** Всё лежит в SQLite на телефоне. Программа хранится как JSON в том же виде, что и YAML-файл, поэтому конструктор, импорт и экспорт работают с одной структурой. При начале тренировки план копируется в неё, и правка программы не ломает историю. Подходы создаются в базе сразу при старте тренировки, поэтому, если приложение закроется, ничего не потеряется.

**Поменять программу кодом.** Отредактируй файл в `programs/` или создай новый, он сам попадёт в приложение при следующей сборке (`npm run gen`). Новое упражнение добавляется в `library/exercises.yaml`.

**Добавить тему.** Новый объект в `src/theme/themes.ts`.

Планы на следующий этап: [ROADMAP.md](ROADMAP.md).
