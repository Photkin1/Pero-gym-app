# Как составить программу для Pero

Программа тренировок в Pero хранится в одном текстовом файле `.yaml`. Его можно:

- собрать прямо в приложении в конструкторе (файл тогда не нужен вообще);
- написать руками на компьютере;
- попросить нейросеть (ChatGPT, Claude, DeepSeek и любую другую) составить его за тебя.

Готовый файл кидаешь на телефон (Telegram, кабель, Google Диск) и в приложении нажимаешь **Программа → Импорт**. Перед импортом Pero проверит файл и покажет понятную ошибку, если что-то не так. Программу из приложения можно и выгрузить обратно в такой же файл, чтобы отправить другу.

## Быстрый способ: попросить нейросеть

Скопируй промпт ниже целиком, впиши свои данные в первые строки и отправь нейросети вместе с этим файлом (`program-format.md`) и файлом библиотеки `exercises.yaml`.

```text
Ты тренер, который опирается на научные исследования по гипертрофии и силе.
Составь мне программу тренировок в формате Pero (описание формата и библиотека
упражнений приложены).

Обо мне:
- пол, возраст, рост, вес:
- опыт тренировок (сколько лет, текущие рабочие веса в базовых):
- цель (масса, сила, рельеф, здоровье):
- сколько дней в неделю и сколько минут на тренировку готов тратить:
- какие дни недели удобны:
- какой сплит хочу (фулбади, верх/низ, тяни-толкай-ноги, по группам мышц или на твой выбор):
- оборудование (полноценный зал, только гантели, дом):
- травмы и ограничения:
- упражнения, которые люблю или не люблю:

Требования:
1. Используй упражнения из библиотеки по их id. Если нужного нет, опиши его
   в custom_exercises.
2. Объём 10–20 рабочих подходов на мышцу в неделю, у новичка ближе к 10.
3. Базовые упражнения: RIR 1–2, изоляция: RIR 0–1. Отдых в базовых 2–3 минуты,
   в изоляции 1–2.
4. Двойная прогрессия по диапазону повторений.
5. Ответь ОДНИМ блоком кода yaml без пояснений внутри, строго по формату
   pero-program/1. После блока коротко объясни, почему программа устроена так.
```

Если нейросеть ошиблась в формате, приложение при импорте покажет, в какой строке ошибка. Скопируй этот текст ошибки обратно нейросети, она исправит.

## Как устроен файл

Минимальная программа, которая уже работает:

```yaml
format: pero-program/1
name: Моя первая программа
schedule:
  type: weekly
  days: { mon: a, thu: b }
workouts:
  - id: a
    name: Тренировка A
    exercises:
      - { exercise: squat, sets: 3, reps: 8-10, rir: 2, rest: 3m }
      - { exercise: bench-press, variant: barbell, sets: 3, reps: 6-10, rir: 1-2, rest: 2m30s }
  - id: b
    name: Тренировка B
    exercises:
      - { exercise: romanian-deadlift, variant: dumbbell, sets: 3, reps: 8-10, rir: 2, rest: 2m30s }
      - { exercise: pull-up, sets: 3, reps: 6-10, rir: 1-2, rest: 2m }
```

Полные примеры лежат в папке `programs/`:

| Файл | Сплит | Дней |
|---|---|---|
| `full-body-3d.yaml` | Фулбади A/B/C | 3 |
| `upper-lower-4d.yaml` | Верх/низ (программа Петра) | 4 |
| `bro-split-5d.yaml` | По группам мышц | 5 |
| `push-pull-legs-6d.yaml` | Тяни-толкай-ноги по кругу | 6 |

### Шапка программы

| Поле | Обязательно | Что это | Пример |
|---|---|---|---|
| `format` | да | Версия формата, всегда `pero-program/1` | `pero-program/1` |
| `name` | да | Название, видно в приложении | `Верх/низ, 4 дня` |
| `author` | нет | Кто составил | `Петр` |
| `description` | нет | Пара предложений, для кого и зачем | |
| `level` | нет | `beginner`, `intermediate` или `advanced` | `intermediate` |
| `units` | нет | `kg` (по умолчанию) или `lb` | `kg` |

### Расписание: `schedule`

Два варианта.

**По дням недели** (`weekly`). Ключи: `mon tue wed thu fri sat sun`, значение: `id` тренировки.

```yaml
schedule:
  type: weekly
  days: { mon: upper-a, tue: lower-a, thu: upper-b, fri: lower-b }
```

**По кругу** (`rotation`). Тренировки идут друг за другом независимо от дня недели, приложение просто предлагает следующую. `rest` означает день отдыха.

```yaml
schedule:
  type: rotation
  order: [push, pull, legs, rest]
```

### Тренировки: `workouts`

Список тренировок. У каждой есть `id` (латиница, цифры, дефисы: `upper-a`), `name` и список `exercises`.

### Упражнение в тренировке

| Поле | Обязательно | Что это | Пример |
|---|---|---|---|
| `exercise` | да | id из библиотеки или из `custom_exercises` | `bench-press` |
| `variant` | нет | Вариант выполнения из библиотеки. Если не указан, в приложении выбирается последний использованный | `dumbbell-30` |
| `sets` | да | Рабочих подходов | `3` |
| `reps` | да | Повторений: число или диапазон. Для упражнений на время с `s` | `8-12`, `10`, `30-60s` |
| `rir` | нет | Повторений в запасе (см. ниже): число или диапазон | `1-2` |
| `rest` | нет | Отдых после подхода: секунды или `2m30s`. По умолчанию 2 минуты | `90s`, `3m` |
| `sides` | нет | `each`: делать по одной руке/ноге, записывать отдельно левую и правую | `each` |
| `group` | нет | Буква суперсета. Подряд идущие упражнения с одной буквой выполняются по очереди | `A` |
| `start_weight` | нет | Стартовый вес в кг для первой тренировки | `70` |
| `note` | нет | Короткая заметка, видна во время тренировки | `С касанием груди` |

Разминочные подходы в `sets` не входят: приложение предлагает их само.

### Что такое RIR

**RIR** (reps in reserve) это сколько повторений ты ещё смог бы сделать в подходе до отказа.

- **0**: больше ни одного, отказ
- **1**: смог бы ещё одно
- **2**: ещё два
- **3**: ещё три
- **4+**: легко, далеко до отказа

Работа с 1–2 повторениями в запасе даёт почти тот же рост мышц, что и до отказа, но меньше утомляет (Refalo 2023, Robinson 2024). Шкала проверена в исследованиях (Helms 2016, Zourdos 2016). В приложении после подхода ты выбираешь RIR одной кнопкой.

### Прогрессия: `progression`

| `type` | Как работает |
|---|---|
| `double` (по умолчанию) | Двойная прогрессия. Работаешь в диапазоне повторений. Когда во всех подходах сделал верхнюю границу с нужным RIR, приложение подсказывает прибавить вес на шаг упражнения |
| `linear` | Каждую удачную тренировку +`increment` кг |
| `none` | Без подсказок |

Шаг прибавки (`increment`) берётся из библиотеки для конкретного упражнения и варианта: штанга +2,5 кг, гантели +2 кг, тренажёры +5 кг. В приложении шаг можно поменять под свой зал.

### Фазы, разгрузка, разминка

```yaml
phases:              # особые недели в начале программы
  - { week: 1, rir: 3, note: Учим технику }
  - { week: 2, rir: 2 }

deload:              # разгрузочная неделя
  every_weeks: 7     # каждые 7 недель
  sets_factor: 0.5   # половина подходов
  rir: 3             # с запасом 3

warmup:
  suggest: true      # предлагать разминочные подходы
  scheme:            # проценты от рабочего веса
    - { percent: 50, reps: 8 }
    - { percent: 70, reps: 4 }
    - { percent: 85, reps: 2 }
```

Разминка предлагается только перед первым базовым упражнением, в котором рабочий вес больше 40 кг. Ты сам решаешь, добавлять её или нет.

### Свои упражнения: `custom_exercises`

Если в библиотеке нет нужного упражнения, опиши его прямо в программе. Формат такой же, как в библиотеке:

```yaml
custom_exercises:
  - id: dead-hang
    name: Вис на турнике
    muscles: { primary: [forearms] }
    type: time            # weight, bodyweight или time
    sides: both           # both, each или optional
    tips:
      - Плечи «включены», не висни на связках
```

## Библиотека упражнений

Файл `library/exercises.yaml`. Поля упражнения:

| Поле | Что это |
|---|---|
| `id` | Уникальный ключ: латиница, цифры, дефисы |
| `name` | Название по-русски |
| `muscles.primary` | Основные мышцы, в недельном объёме считаются как 1 подход |
| `muscles.secondary` | Вспомогательные, считаются как 0,5 подхода |
| `type` | `weight` (вес × повторы), `bodyweight` (свой вес, можно с доп. весом), `time` (секунды) |
| `sides` | `both` всегда двумя, `each` всегда по одной, `optional` переключатель в приложении |
| `increment` | Шаг прибавки веса в кг |
| `variants` | Варианты: штанга, гантели, угол скамьи, хват. У каждого свой `id`, `name` и можно свой `increment`. Веса и рекорды хранятся отдельно для каждого варианта |
| `tips` | Пункты техники, видны по кнопке «Подробнее» |
| `video` | Ссылка на видео. Если нет, приложение открывает поиск на YouTube |
| `image` | Картинка упражнения |

Мышцы (`muscles`): `chest` грудь, `lats` широчайшие, `upper_back` середина спины, `lower_back` поясница, `traps` трапеции, `front_delts` передняя дельта, `side_delts` средняя дельта, `rear_delts` задняя дельта, `biceps`, `triceps`, `forearms` предплечья, `quads` квадрицепс, `hamstrings` бицепс бедра, `glutes` ягодицы, `adductors` приводящие, `abductors` отводящие, `calves` икры, `abs` пресс.

## Частая ошибка: двоеточия и запятые в тексте

Если в заметке или подсказке есть двоеточие с пробелом или запятая внутри `{ ... }`, бери текст в кавычки, иначе YAML поймёт его неправильно:

```yaml
- { exercise: pull-up, sets: 3, reps: 6-10, note: "Вес добавляй, когда во всех подходах 10+" }
tips:
  - "Сидя лучше, чем лёжа: больше роста"
```

## Проверка файла

Точное описание формата для программ лежит в `schema/program.schema.json` (JSON Schema). Редакторы вроде VS Code с расширением YAML подсказывают поля и подсвечивают ошибки, если в начале файла добавить строку:

```yaml
# yaml-language-server: $schema=../schema/program.schema.json
```
